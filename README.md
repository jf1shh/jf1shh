An independent, local-first claims retrieval project built with AI coding agents on synthetic data. It combines hybrid retrieval, reranking, claim-scoped documents, source citations, and measured answer-quality and adversarial evaluations. Human judgment stays responsible for claims decisions. The README records dated evaluation results and their limits; this is a portfolio proof of concept.

[Repository and evaluation](https://github.com/jf1shh/claims-rag)

### Agentic App Harness

A spec-driven framework for AI-assisted app development, with six deployed web and mobile app demos. Contract-first Zod schemas, behavior-driven unit and end-to-end tests, and automated accessibility checks run in CI. A deterministic Sense → Propose → Act → Verify → Learn loop detects drift and generates work orders for a coding agent, with no embedded LLM or API key.

[Live showcase](https://jf1shh.github.io/agentic-app-harness/) · [Repository](https://github.com/jf1shh/agentic-app-harness)

## Claims experience and AI enablement

My appraisal work covered supplement review, total loss determinations, fraud indicators, subrogation, and complex shop disputes. That experience shapes how I define requirements: usable guidance, traceable evidence, and a clear boundary between an assistant's output and a person's decision.

At Liberty Mutual, I designed and piloted a RAG-based appraisal assistant and built and demoed a total-loss assistant. I also built PII scrubbing and photo PII redaction tools that were distributed to the team, wrote a department expansion playbook, built a prompt library, and ran a cross-team training session. The assistants were pilots and demos; they were not deployed team-wide.
